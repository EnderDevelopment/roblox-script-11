# Roblox Script: Teleport to Money Trees

This Roblox script teleports players to money trees in the game. It is designed to be placed in the `ServerScriptService` folder in Roblox Studio. The script assumes that money trees are named "MoneyTree" or have a child object named "IsMoneyTree". If no money trees are found, a warning will be printed to the Output window in Roblox Studio.

## Install

1. Open Roblox Studio and load your game.
2. Navigate to the `ServerScriptService` folder in the Explorer.
3. Right-click and select `Insert Object` > `Script`.
4. Name the script `TeleportToMoneyTrees`.
5. Copy and paste the contents of `TeleportToMoneyTrees.server.lua` into the script.
6. Save your game.

## Use

1. Open Roblox Studio and load your game.
2. Navigate to the `ServerScriptService` folder in the Explorer.
3. Open the `TeleportToMoneyTrees` script.
4. Ensure the script is named `TeleportToMoneyTrees` and is placed in the `ServerScriptService` folder.
5. Save your game and test it in Roblox Studio or publish it to Roblox.
